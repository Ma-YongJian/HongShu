## 怎么选版本

> 开源版免费学习、跑通社区。需要闲置、商城、AI、微服务或演示站同款，按档购买即可。源码未加密，允许二开与自行上线。

| 你的目标                                            | 建议 |
|-------------------------------------------------|------|
| 学习 SpringBoot + Vue + UniApp，跑通笔记社区             | **开源版（本仓库，免费）** |
| 毕设 / 个人，要闲置交易 + 支付 + UniApp 完整能力                | **单体版** |
| 团队要拆服务、网关、多实例 IM                                | **微服务版** |
| 要大模型创作 / 机审                                     | **微服务-AI 版** |
| 要系统商城 + 商家端                                     | **微服务-Shop 版** |
| 要演示站同款（AI + 商城 + Flutter + Electron + 直播 + VIP） | **全端版（推荐）** |

## 本仓库（开源版）是什么

> 便于你克隆后预期一致，避免和演示站功能对不上。想要对齐演示站，请购买对应 Pro 档。

| | 开源版实际情况                                                                          |
|--|----------------------------------------------------------------------------------|
| 后端 | Spring Boot **单体**（本仓库）· JDK 8 · MySQL · Redis · WebSocket + Redis MQ            |
| 前端 | [HongShu-Ui](https://gitee.com/Maverick_Ma/hongshu-ui)：Vue3 Web、RuoYi 管理端、UniApp |
| 有 | 发现 / 发布图文 · 赞藏评关 · 专辑标签 · 文本私信 · 本地/MinIO                                        |
| 没有 | 微服务拆分、闲置/商城/支付、AI、直播、Flutter、Electron、因讯、商家端、创作中心                                |
